# 2026-07-30

## Bitcoin Core true-solo architecture

Implemented a separate Bitcoin Core RPC and complete-block mining boundary.
The milestone added strict environment-only authentication, non-wallet payout
validation, immutable modern templates, independent transaction identities and
SegWit commitment checks, BIP34 coinbase construction, complete merkle/header
and block assembly, finite strategy/backend orchestration, stale-candidate
suppression, mandatory proposal validation, one-shot submission, read-only
readiness, sanitized events, and true-solo log aggregation.

Normal tests use deterministic transports, templates, backends, clocks, and
stop controls. The isolated regtest gate is implemented but was not executed
because a compatible existing `bitcoind` was unavailable. No package was
installed, no wallet or node configuration was touched, no CKPool connection
was opened, and no mainnet block was submitted.
