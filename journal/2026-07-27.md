# Bounded Live Mining and Notification Polling

## Milestone Status

The first opt-in bounded live Stratum mining command is complete. It performs
one caller-bounded nonce range and can submit at most one qualifying result.
It does not continue into another range automatically.

Timeout-aware Stratum notification polling is the current milestone. The new
boundary lets an authorized client return queued notifications immediately or
wait for a caller-bounded duration without treating a normal timeout as a
connection failure. Chunked mining orchestration remains deferred.
