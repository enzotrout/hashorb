## Parallel Native CPU Backend

The `native-parallel` backend now uses deterministic nonoverlapping assignments
and a persistent portable Python thread pool around the GIL-releasing verified
native scanner. It selects the lowest qualifying nonce independent of worker
completion order, reports actual aggregate hashes over wall-clock time, and
closes all worker resources on every command exit path. This validation was the
gate before the search-strategy abstraction.

## Search-Strategy Milestone

Parent nonce scheduling is now separate from compute execution. The
`sequential` reference strategy preserves the existing ascending contiguous
order across Python, native, and native-parallel backends. One strategy is
selected per invocation, while fresh compact cursor state belongs to each
effective work variant and resets after legitimate work or session changes.
That abstraction was the gate for the orbiting-bit milestone recorded below.

## Orbiting-Bit Strategy

The experimental `orbiting-bit` strategy now schedules the same contiguous
parent ranges through deterministic physical-index bit reversal. It preserves
complete nonrepeating coverage and leaves compute, Stratum, progression,
recovery, and submission behavior unchanged. It changes ordering only and does
not claim improved Bitcoin probability. A correctness-first GPU/CUDA backend is
the next compute milestone.
