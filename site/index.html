HashOrb

A hands-on project for learning how Bitcoin mining works while exploring GPU compute, search strategies, CI/CD, and AI-assisted software engineering.

View on GitHub See examples
Why this exists

Learning by building something real.

HashOrb started with a simple question: can I build a Bitcoin hashing system from the ground up and use the process to better understand both Bitcoin and modern AI-assisted engineering?

Learning Bitcoin

Using working code to understand the mechanics behind mining instead of treating Bitcoin as a black box.

  • Block headers and double SHA-256
  • Targets, difficulty, nonces, and search spaces
  • Stratum jobs and share submission
  • Bitcoin Core RPC and solo mining concepts

Learning AI-assisted engineering

Using AI as a practical engineering tool while keeping correctness, tests, and security independently verifiable.

  • GitHub Copilot for implementation and refactoring
  • AI-assisted troubleshooting and code review
  • Test generation and documentation workflows
  • Exploration of agent-assisted development

Built as an engineering playground.

Examples

Safe, offline commands first.

Diagnostics and benchmarks can be explored without connecting to a mining pool or using a Bitcoin wallet.

hashorb — terminal
# Check the local environment
$ hashorb doctor

# CPU correctness / benchmark path
$ hashorb compute-benchmark \
    --backend python \
    --hash-count 100000

# NVIDIA CUDA benchmark
$ hashorb compute-benchmark \
    --backend cuda \
    --device 0 \
    --hash-count 1000000
Engineering

More than hashing code.

The project is also a way to practice the habits behind maintainable software: automation, documentation, CI/CD, reproducibility, testing, and security.

CI/CD

GitHub Actions workflows, pull-request based development, reproducible tooling, and automated checks.

Quality

Unit and regression testing, static analysis, type checking, benchmarking, and multiple compute backends.

Security

Dependency, secret, source, and container scanning using tools including Gitleaks, Trivy, Bandit, and pip-audit.

Active development / pre-release

HashOrb is a learning and experimentation project. It is not intended to compete with ASIC mining hardware and does not claim to improve the probability of finding a valid Bitcoin hash.
